================================================================
ScottsTechX — BUILD INSTRUCTIONS FOR AN AI WITH NO SOURCE CODE
================================================================

You are building ScottsTechX from scratch: an Android marketplace
app + Fastify backend for Uganda. The owner is Kato Fred, an
Ugandan cybersecurity analyst.

The app has two roles: BUYER and SELLER, each with its own bottom
nav, dashboard, AI assistant, settings, and messaging inbox.

================================================================
PHASE 1 — DECIDE THE STACK
================================================================

Pick these technologies. Do not substitute them unless told otherwise.

  ANDROID (frontend)
    Language       : Kotlin 1.9+
    UI             : Jetpack Compose (BOM 2024.06.00+)
    Min SDK        : 30 (Android 11)
    Target SDK     : 35 (Android 15)
    Build tool     : Gradle 8.5 with kotlin DSL
    JDK            : 17.0.19 (use the exact toolchain)
    Navigation     : androidx.navigation.compose 2.7.x
    State          : Compose State + collectAsState + rememberCoroutineScope
    Image loading  : Coil 2.6.x with a custom ImageLoaderFactory
    Auth           : Firebase Auth (com.google.firebase:firebase-auth-ktx)
    HTTP           : OkHttp 4.12 + built-in org.json (NO Retrofit/Moshi)
    Coroutines     : kotlinx-coroutines-android 1.8.x
    In-memory DB   : none needed; data lives in V2Client + DataStore

  BACKEND (server)
    Runtime        : Node.js 20.x
    Framework      : Fastify 5.x with @fastify/cors
    Language       : TypeScript 5.x (compile with tsx or tsc)
    Database       : PostgreSQL via `pg` 8.x
    Local Postgres : `embedded-postgres` package, port 5433
    API port       : 3001
    Auth           : bcrypt 5.x + `jose` for JWT (HS256, 24h expiry)
    Validation     : zod 4.x
    Email          : Firebase Admin SDK (firebase-admin 12.x)
                     uses generateEmailVerificationLink
    AI             : OpenRouter (https://openrouter.ai)
                     default model meta-llama/llama-3.3-70b-instruct
    Payments       : Stripe 17.x (skeleton only for now)
    Migrations     : raw SQL files run in alphabetical order on boot

  SHARED
    Version control: git (single repo, branch `fix/embedded-postgres-linux-build`)
    Env file       : 12_Backend/.env (PORT=3001, JWT_SECRET=..., LLM_API_KEY=...,
                     AI_PROVIDER=openrouter, AI_MODEL=...,
                     GOOGLE_CLIENT_ID=...)

      bcrypt jose firebase-admin stripe zod dotenv
  npm i -D typescript @types/node @types/pg @types/bcrypt tsx

Create tsconfig.json:

    "compilerOptions": {

      "module": "NodeNext",

      "strict": true,
      "esModuleInterop": true,
      "outDir": "dist",

Add to package.json:

2.2. Create src/db.ts
----------------------------------------------------------------
Single shared pg.Pool that connects lazily to:
  process.env.DATABASE_URL || "postgresql://app:app@127.0.0.1:5433/scottstechx"

If DATABASE_URL is empty, the server should boot an embedded
Postgres on 127.0.0.1:5433 and create a database `scottstechx`
with user `app` / password `app`, then run all SQL files in
migrations/ in alphabetical order, then call the same pool.

2.3. Create src/auth.ts
----------------------------------------------------------------
  - bcrypt.hash / bcrypt.compare
  - signJwt(payload) -> HS256 JWT, 24h expiry, issuer "scottstechx",
    audience "scottstechx-api"
  - verifyJwt(token) -> payload or throw UnauthorizedError
  - requireAuth: Fastify preHandler that reads Bearer header and
    attaches request.user

2.4. Create src/firebase/admin.ts
----------------------------------------------------------------
  - initializeApp() with service account JSON at secrets/firebase-admin-key.json
  - exports getFirebaseAuth(), verifyIdToken(idToken), getFirestore()

2.5. Build these route modules (one file each under src/modules/<area>/)
----------------------------------------------------------------
  auth/login.route.ts
    POST /api/v1/auth/register
      body: { email, password, displayName, phone, role }
      -> bcrypt hash, insert users row, sign JWT, return { token, user }
    POST /api/v1/auth/login
      -> verify bcrypt, sign JWT, return { token, user }
    GET  /api/v1/auth/me           (requireAuth)
    PATCH /api/v1/auth/me          (requireAuth) update profile fields
    PATCH /api/v1/me/location      (requireAuth) update lat/lng/city

  auth/firebase-auth.route.ts
    POST /api/v1/auth/firebase/sign-in
      body: { idToken } -> verifyIdToken, upsert users row, sign JWT
    POST /api/v1/auth/firebase/send-verification-email
      body: { idToken }
      -> Firebase auth.generateEmailVerificationLink(email, { url: APP_DEEP_LINK })
      -> Firebase automatically emails the link. Return ok.
    GET  /api/v1/auth/firebase/me   (requireAuth)
      -> return { id, email, displayName, role, emailVerified, firebaseUid }
    POST /api/v1/auth/firebase/upgrade-to-seller
      -> guard: requireAuth, require emailVerified
      -> update users.role = 'seller' and copy seller fields

  auth/google.route.ts
    POST /api/v1/auth/google
      body: { idToken } (Google OAuth)
      -> exchange via google-auth-library, sign JWT

  products/products.route.ts + products.service.ts
    GET /api/v1/products
      -> SELECT products joined with product_media, plus seller info
      -> COALESCE(product_media.url, products.image_url) AS image_url
      -> return array of:
         { id, title, description, category, priceMinor, oldPriceMinor,
           currency="UGX", stockQuantity, imageUrl, rating, ratingCount,
           seller: { id, name, rating, location, verified }, location }
    GET /api/v1/products/:id
    POST /api/v1/seller/products        (requireAuth + role=seller)
    GET  /api/v1/seller/products        (requireAuth + role=seller)
    DELETE /api/v1/seller/products/:id  (requireAuth + role=seller)

  seller/store-settings.route.ts
    GET  /api/v1/seller/store-settings       (requireAuth + role=seller)

      business-info: { legalName, tin, businessEmail, businessPhone }
      store-location: { address, pickupInstructions, serviceRadiusKm }

    GET /api/v1/sellers/:id
    GET /api/v1/seller/dashboard/stats      (requireAuth + role=seller)
      -> revenue, orders, top product, low-stock count

  user/user-full.route.ts
    Register these (all requireAuth):
      GET/POST/PATCH/DELETE /api/v1/me/addresses

----------------------------------------------------------------  @Composable fun ProductImage(
      imageKey: String,
      categoryLabel: String,
      imageUrl: String? = null,
      modifier: Modifier = Modifier,
  ) {
      // Use Coil.imageLoader(LocalContext.current) — NOT a fresh
      // ImageLoader.Builder(ctx).build() (that drops network requests).
      val loader = Coil.imageLoader(LocalContext.current)
      val palette = remember(imageKey) { pickPalette(imageKey) }
      Box(modifier) {
          if (!imageUrl.isNullOrBlank()) {
              AsyncImage(
                  model = ImageRequest.Builder(LocalContext.current)
                      .data(imageUrl)
                      .crossfade(true)
                      .build(),
                  imageLoader = loader,
                  contentDescription = categoryLabel,
                  contentScale = ContentScale.Crop,
                  modifier = Modifier.fillMaxSize(),
              )
          } else {
              // Gradient placeholder with category letter
              Box(modifier = Modifier.fillMaxSize().background(palette))
              Text(categoryLabel.first().uppercase(),
                   color = Color.White, fontSize = 48.sp, fontWeight = Bold,
                   modifier = Modifier.align(Center))
          }
      }
  }
